# How fast will my server be setup?

We aim to provide the fastest possible setup times for game and voice services.

Our normal setup times:

*   Game servers:
    Set up automatically as soon as your payment is confirmed. Your server is usually online within a few minutes.

*   Voice servers:
    Set up automatically as soon as your payment is confirmed.

*   Dedicated servers:
    Set up by our team. [Open a support ticket](VAR::SUPPORT_URL) in the **Sales** category for availability and setup times.

Payments by card, PayPal or wallet balance are confirmed straight away. A few payment methods can take a little longer to confirm; setup starts as soon as they are. You can follow the setup on the order page, and the server appears under **My servers** in the [Fragnet dashboard](VAR::PANEL_URL) when it's ready.

If your server isn't set up after a while, [open a support ticket](VAR::SUPPORT_URL) in the **Billing** category and choose **Instant setup issue**.
