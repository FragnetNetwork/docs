# Kicking players from your Left 4 Dead 2 server
Kicking players from your server is simple. You use the server console in the [Fragnet dashboard](VAR::PANEL_URL).

1. Open the [Fragnet dashboard](VAR::PANEL_URL), go to **My servers** and select your server. The **Console** card is on the **Overview** tab.

2. Click in the **Enter a command…** field at the bottom of the console.

3. Type in `kick playername` and press **Enter**. That kicks the player you have chosen. See [Send a command](../../control-panel/basics.md#send-a-command).

:::tip
If the player's name has spaces, put it in quotes: `kick "player name"`. You can also type `status` to list the players on the server with their user IDs, then kick by ID with `kickid` followed by the user ID.
:::
