# Change ARK server's name

The name players see in the ARK server list is the **Server Name** startup setting.

1. Open the [Fragnet dashboard](VAR::PANEL_URL), go to **My servers** and select your ARK server.
2. Open the **Configuration** tab and select **General** in the list on the left.
3. In the **Startup** group, find **Server Name** and enter the name you want.
4. Select **Save** in the bar at the bottom of the page.
5. Restart the server: open ⋯ **More actions** at the top of the page and select **Restart**. The new name shows once the server is back up.

See [Change a setting under General](../../control-panel/configuration.md#under-general) for more on saving these settings.

:::tip
The name of the server in your dashboard lists is separate. Only you and your team see it. See [Rename the server](../../control-panel/basics.md#rename-the-server).
:::
